ATS QUICKSTART
==============

TRAIN
  Double-click Train.bat          headless, never stops on its own, resumes the saved brain
  Watch training.bat              small window: how the run is going
  Trend.bat                       reward by quarter, deaths by cause

RUN THE SIM
  py -3 main.py --episodes 2      the pygame CRT window (ESC to quit)
  py -3 main.py --no-gui          headless

TESTS (from the ATS folder)
  py -3 tests/test_loop.py        one file; every tests/test_*.py runs the same way

TOOLS
  tools/                          diagnostics and helpers - training never imports them

MOD ITEMS / ENTITIES
  Edit assets/items.json or entities.json; restart main.py

DOCS
  README.md, AGENTS.md, docs/, updates/ (one note per change)
